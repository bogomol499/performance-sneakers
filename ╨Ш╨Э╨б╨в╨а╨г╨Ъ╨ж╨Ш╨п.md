# Как выложить сайт на GitHub

Точно так же, как с сайтом кафе. Сервер не нужен, GitHub Pages сам покажет сайт по ссылке:

**https://bogomol499.github.io/performance-sneakers/**

## 1. Распакуйте архив

Правой кнопкой на `performance-sneakers.zip` → «Извлечь все…» → «Извлечь». Откройте папку `performance-sneakers`.

## 2. Создайте репозиторий

github.com → **+** → **New repository** → имя `performance-sneakers` → **Public** → **Create repository**.

## 3. Загрузите файлы

Нажмите ссылку **uploading an existing file**. В папке нажмите `Ctrl + A` и перетащите всё в окно браузера. Перетаскивайте содержимое папки, а не саму папку. Потом нажмите **Commit changes**.

## 4. Включите сайт

Откройте https://github.com/bogomol499/performance-sneakers/settings/pages → в **Branch** выберите `main` и `/ (root)` → **Save**. Через 2–3 минуты сайт откроется по ссылке.

## 5. Для портфолио

На главной странице репозитория, в блоке **About**, нажмите шестерёнку и поставьте галочку **Use your GitHub Pages website**.

## Как обновлять

Измените файлы, в `sw.js` поменяйте версию (`pf-sneakers-v1` → `pf-sneakers-v2`), загрузите файлы заново через **Add file → Upload files**.

## Как поменять кроссовки или цены

Всё в файле `js/data.js`, в списке `PRODUCTS`. Фото лежат в папке `img/` (список `FILES` в начале файла), `gender`: `m` — мужские, `w` — женские, `u` — унисекс.
