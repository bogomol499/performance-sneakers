# Performance — магазин кроссовок в Москве

Учебный проект для портфолио: сайт вымышленного магазина кроссовок на Покровке. В каталоге настоящие модели Nike, Adidas и Golden Goose, разделы «Мужчинам» и «Женщинам», корзина, избранное, дроп с таймером и подбор размера.

**Открыть сайт:** https://bogomol499.github.io/performance-sneakers/

![Превью](icons/og.png)

## Что умеет сайт

- **Загрузка:** буквы PERFORMANCE выезжают по одной, полоса заполняется, экран уезжает вверх.
- **Витрина:** четыре пары сменяют друг друга «шторкой», рамка наклоняется за мышью, на телефоне листается свайпом.
- **Мужчинам / Женщинам:** две большие карточки, при наведении одна плавно расширяется.
- **Каталог:** 14 пар, фильтр «для кого», фильтр по брендам, сортировка по цене. Карточки прилетают при прокрутке и наклоняются в 3D за мышью.
- **Карточка товара:** своя размерная сетка для мужских, женских и унисекс-моделей, размеры «нет в наличии» зачёркнуты.
- **Корзина:** количество, промокоды (`POKROVKA10`, `ПЕРВЫЙ`), три способа доставки, бесплатный курьер от 20 000 ₽, оформление с проверкой полей.
- **Избранное:** сердечко на карточке, отдельная панель со списком.
- **Дроп:** таймер до пятницы 12:00 по Москве, подписка на напоминание.
- **Подбор размера:** ползунок длины стопы, мужская и женская сетки EU и US.
- **Лукбук:** лента фото, которую можно тянуть мышкой или пальцем, и просмотр крупно.
- **Приложение:** ставится на телефон и работает без интернета после первого открытия.

## Технологии

HTML, CSS и JavaScript без библиотек. Scroll-анимации на своём движке, Web Animations API, Service Worker, localStorage.

## Структура

```
index.html            страница
css/style.css         стили
js/data.js            каталог: модели, фото, размеры, промокоды, доставка
js/app.js             логика магазина
js/motion.js          анимации при прокрутке
sw.js                 работа без интернета
```

## Фото

Все фото — с [Unsplash](https://unsplash.com), бесплатная лицензия, и лежат в папке `img/`, поэтому сайт работает и без интернета. Имена авторов показаны на сайте: кнопка «Авторы фото» внизу страницы и подпись в карточке каждой пары.
